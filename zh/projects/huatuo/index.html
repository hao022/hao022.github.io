HUATUO, 华佗

HUATUO 华佗，由滴滴开源并依托中国计算机学会（CCF）孵化的操作系统内核/Agent 沙箱全景观测项目。广泛应用于AI 沙箱、AI 计算、通用计算、云原生、智驾系统等基础设施服务。

GitHub 仓库 项目文档

核心特点

  • 内核全景观测：覆盖内存管理、CPU 调度、网络和块 I/O 等 Linux 内核子系统，以较低性能开销提供细粒度观测数据。
  • 异常事件诊断：在缺页、调度延迟等慢路径事件发生时，自动采集内核运行上下文，帮助快速定位问题。
  • 全自动化追踪：通过自动快照留存捕获偶发性能抖动，辅助分析 CPU idle 降低、sys 使用率突增、I/O 或 Load Average 突增等问题。
  • 持续性能剖析：持续分析操作系统及应用的 CPU、内存、I/O 和锁，为高可用、稳定性工程与性能优化提供依据。
  • 异构硬件观测：全面覆盖 CPU、内存、PCIe、网卡、存储等通用基础设施，并深度扩展至 GPU、NPU 等 AI 加速器。

生态集成

HUATUO 可与 Prometheus、Grafana、Pyroscope 和 Elasticsearch 等主流可观测组件集成，并自动关联 Kubernetes 容器标签与注解。基于内核级 eBPF 编程，无需修改业务代码即可获得跨硬件平台和 Linux 发行版的系统观测数据。
